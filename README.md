# Intro to Python — Course Homework Archive

**Status: historical Python learning exercises**, not a production application or a featured professional portfolio project.

This repository preserves coursework from an introductory Python training program. The exercises are grouped by lesson in `lesson_1/` through `lesson_7/`, with individual `homework_*.py` scripts and package markers.

## Exploring the exercises

Use a recent Python installation and inspect each script before running it. For example:

```bash
python lesson_1/homework_1_1.py
```

Individual scripts may expect terminal input or have their own assumptions. A repository-wide dependency manifest, CI workflow and verified automated test suite are **not present**, and execution has not been independently verified during this GitHub audit.
